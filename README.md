# AsteriumLand — Revisão online

Portal estático para GitHub Pages, com login e arquivos privados no Supabase. Os vídeos não são enviados ao GitHub.

Configuração pública em config.js contém somente a URL do projeto e a chave publicável. Credenciais administrativas e arquivos locais ficam fora do repositório.

As avaliações são associadas ao ID e SHA-256 da versão do vídeo. A revisão de uma nova versão não herda aprovação da anterior.
